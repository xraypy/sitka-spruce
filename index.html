Sitka Spruce: hierarchical data browser¶

Sitka Spruce is a general-purpose data browser for hierarchical datasets stored in HDF5 files or Zarr folders. It allows interactive plotting of scientific data using combining wxPython , wxmplot, and matplotlib.

For goals and motivation for Sitka, see Motivation for Sitka Spruce.
